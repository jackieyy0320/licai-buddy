### 1.2 架构特点

| 特点 | 说明 |
|------|------|
| **前后端一体** | Next.js 同时处理前端渲染和 API 请求 |
| **本地存储** | SQLite 数据库文件存储在本地，无云端依赖 |
| **增量加载** | 页面级代码分割，按需加载 |
| **类型安全** | TypeScript + Prisma，编译时类型检查 |

## 五、安全架构

### 5.1 安全措施

| 层级 | 措施 | 说明 |
|------|------|------|
| 输入验证 | Zod Schema | 所有输入进行 schema 验证 |
| SQL 注入 | Prisma ORM | 参数化查询，无原生 SQL |
| XSS 攻击 | React 转义 | 自动转义，防 XSS |
| CSRF | SameSite Cookie | 防止跨站请求伪造 |
| 敏感数据 | 本地加密 | 密码等敏感数据本地加密 |

### 5.2 数据隐私

- 所有数据存储在本地 SQLite 文件
- 无云端同步
- 无第三方数据上报
- 用户完全控制自己的数据

```
┌─────────────────────────────────────────────────────────────┐
│                      本地部署                                │

│  │              Next.js 应用                            │  │

│  │  │ 开发环境 │  │ 生产环境 │  │ 测试环境 │          │  │
```

### 7.2 部署步骤

1. 安装依赖：`npm install`
2. 初始化数据库：`npx prisma db push`
3. 构建生产包：`npm run build`
4. 启动服务：`npm start`

## 八、技术选型理由

| 技术 | 选型理由 |
|------|----------|
| Next.js 14 | SSR/SSG 支持，App Router 最新实践，生态完善 |
| TypeScript | 类型安全，减少运行时错误，提升开发体验 |
| Tailwind CSS | 原子化 CSS，快速开发，无需写 CSS 文件 |
| shadcn/ui | 基于 Radix UI，可定制，无依赖，组件质量高 |
| SQLite | 轻量级，无需安装服务器，本地文件存储符合隐私需求 |
| Prisma | ORM 工具，类型安全，迁移方便，支持 SQLite |
| Recharts | React 图表库，易用，可扩展 |
| React Hook Form | 高性能表单库，集成 Zod 验证 |
