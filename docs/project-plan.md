## 一、项目概述

| 项目 | 内容 |
|------|------|
| **项目名称** | Licai Buddy |
| **一句话描述** | 多用户记账工具，消费→库存→投资数据联动 |
| **目标用户** | 25-40岁，有记账+理财需求，注重隐私的个人用户 |
| **商业模式** | 免费开源 |
| **核心价值** | 多用户记账，消费→库存→投资数据联动 |
| **用户模式** | 邀请注册，管理员生成邀请码 |
| **MVP 范围** | 用户认证 + 记账明细 + 账户管理 + 报表统计 |

## 四、技术架构

### 4.1 技术栈

```
前端框架：Next.js 14 (App Router)
语言：TypeScript 5.x
样式：Tailwind CSS 3.x + shadcn/ui
数据库：SQLite + Prisma 5.x
认证：JWT (jsonwebtoken) + bcryptjs
图表：Recharts
表单：React Hook Form + Zod
测试：Jest + Playwright
```

## 八、质量保证

### 8.1 验收标准

每个 Task 完成后必须满足：

- [ ] 所有测试通过（`npm test`）
- [ ] 代码符合规范（`npm run lint`）
- [ ] 无 TypeScript 错误
- [ ] 文档已更新
- [ ] 预览链接可访问

### 8.2 代码审核清单

```
□ 功能是否符合需求文档
□ 代码是否符合规范（命名/注释/结构）
□ 是否有单元测试
□ 是否有性能问题
□ 是否有安全问题
```

### 8.3 质量检查点

```
1. 里程碑评审（每个阶段结束）
2. 功能验收（每个用户故事完成）
3. 回归测试（新功能不影响旧功能）
4. 用户验收（Jackie 最终确认）
```

## 十、UI设计规范（温暖友好风格）

### 10.1 设计参考

| 参考产品 | 特点 |
|----------|------|
| **Notion** | 柔和色彩、圆角设计、友好的排版 |
| **Airtable** | 清晰的层次、温暖的色调、易用性优先 |
| **Linear** | 简洁但不冰冷、有温度的设计 |

### 10.2 色彩系统

**主色系（温暖色调）：**
```
主色：#6366F1（柔和靛蓝）
主色 hover：#4F46E3
主色 light：#EEF2FF
```

**辅助色（温暖感）：**
```
成功：#10B981（绿色）
警告：#F59E0B（琥珀色）
危险：#EF4444（红色）
信息：#3B82F6（蓝色）
```

**中性色（柔和感）：**
```
文字主色：#1F2937
文字次色：#6B7280
边框色：#E5E7EB
背景色：#FAFAF9（米白）
卡片背景：#FFFFFF
```

### 10.3 字体系统

```
字体族：Inter
字重：300（细）、400（常规）、500（medium）、600（semibold）
```

| 用途 | 大小 | 字重 | 行高 |
|------|------|------|------|
| 标题 | 24px | 600 | 1.3 |
| 副标题 | 18px | 600 | 1.4 |
| 正文 | 14px | 400 | 1.5 |
| 辅助文字 | 12px | 400 | 1.4 |

### 10.4 圆角系统（更圆润）

```
小：6px
中：10px
大：14px
全圆：50px（按钮）
```
