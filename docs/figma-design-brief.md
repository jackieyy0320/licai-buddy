## 一、设计概述

### 1.1 产品定位

| 项目 | 内容 |
|------|------|
| **产品名称** | Licai Buddy |
| **产品定位** | 一体化工具记账，让每一笔消费关联到资产与收益 |
| **核心价值** | 消费 → 库存 → 投资 数据联动 |
| **目标用户** | 25-40岁，有记账+理财需求，注重隐私 |
| **设计风格** | 简洁、专业、温暖 |

### 1.2 设计目标

1. **易用性** — 操作简单，3 秒完成记账
2. **清晰性** — 数据展示清晰，一目了然
3. **一致性** — 设计风格统一，符合品牌调性
4. **响应式** — 支持桌面和移动端

## 四、页面详细需求

### 4.1 首页 Dashboard

**核心内容：**
1. **本月收支概览**
   - 本月收入总额
   - 本月支出总额
   - 本月结余
   - 较上月变化趋势

2. **快捷操作**
   - 快速记账按钮（悬浮按钮）
   - 最近交易列表（5 条）

3. **账户余额**
   - 所有账户余额汇总
   - 账户余额分布饼图

**设计要点：**
- 数据清晰易读
- 快捷操作显眼
- 移动端友好

### 4.2 记账页 Transactions

**核心内容：**
1. **筛选栏**
   - 日期范围选择器
   - 类别筛选下拉
   - 搜索框

2. **交易列表**
   - 按日期分组
   - 每条显示：类别图标、金额、备注、日期
   - 收入绿色，支出红色

3. **添加交易表单（弹窗）**
   - 类型选择：收入/支出/转账
   - 金额输入
   - 类别选择
   - 账户选择
   - 日期选择
   - 备注输入
   - 提交按钮

**设计要点：**
- 列表紧凑但不拥挤
- 筛选操作便捷
- 表单简洁高效

### 4.3 账户页 Accounts

**核心内容：**
1. **账户列表**
   - 每个账户显示：名称、类型图标、余额
   - 点击可查看详情（流水）

2. **添加账户表单（弹窗）**
   - 账户名称
   - 账户类型选择
   - 初始余额
   - 提交按钮

**设计要点：**
- 余额醒目
- 类型图标清晰
- 操作便捷

### 4.4 报表页 Reports

**核心内容：**
1. **月度收支图表**
   - 柱状图：每月收入 vs 支出
   - 折线图：结余趋势

2. **分类支出占比**
   - 饼图：各分类占比

3. **数据导出**
   - 导出按钮（CSV/Excel）

**设计要点：**
- 图表清晰美观
- 数据直观易懂
- 导出操作便捷

## 五、交互规范

### 5.1 按钮状态

| 状态 | 说明 | 样式 |
|------|------|------|
| Default | 默认状态 | 主色背景 |
| Hover | 鼠标悬停 | 主色加深 10% |
| Active | 点击状态 | 主色加深 20% |
| Disabled | 禁用状态 | 灰色背景 |

### 5.2 弹窗规范

- 最大宽度：500px
- 圆角：12px
- 阴影：升起的阴影效果
- 关闭方式：点击遮罩、点击关闭按钮、ESC 键

### 5.3 列表规范

- 单条高度：56px
- 行间距：8px
- 分隔线：浅色边框
- 空状态：显示引导图标和文字

### 5.4 表单规范

- 输入框高度：40px
- 标签位置：上方
- 错误提示：红色文字，显示在输入框下方
- 必填标记：红色星号
