## 二、设计规范

### 2.1 色彩系统

**主色（Primary）：**
```
#4F46E5 - 主色（靛蓝）
#4338CA - 主色 Hover
#EEF2FF - 主色 Light（背景高亮）
```

**辅助色：**
```
#10B981 - 成功（收入、成功状态）
#F59E0B - 警告（提醒、注意）
#EF4444 - 危险（支出、错误）
#3B82F6 - 信息（提示、信息）
```

**中性色：**
```
#111827 - 文字主色
#6B7280 - 文字次色
#E5E7EB - 边框色
#F9FAFB - 页面背景
#FFFFFF - 卡片背景
```

### 2.2 字体系统

```
字体族：Inter
```

| 用途 | 大小 | 字重 | 行高 |
|------|------|------|------|
| 标题 | 24px | 600 | 1.3 |
| 副标题 | 18px | 600 | 1.4 |
| 正文 | 14px | 400 | 1.5 |
| 辅助文字 | 12px | 400 | 1.4 |

### 2.3 间距系统

```
4px, 8px, 12px, 16px, 24px, 32px
```

### 2.4 圆角系统

```
4px - 小元素

```

## 三、各页面详细规格

### 3.1 登录页 / 注册页

**画板：** 375 x 812 (iPhone) 居中，背景 #F9FAFB

**布局结构：**
```
[顶部空白 80px]
    │
    ▼
┌─────────────────────┐
│                     │
│   [Logo] Licai      │  ← 间距 24px
│      Buddy          │
│                     │
│   ───────────────── │  ← 间距 32px
│                     │
│   [邮箱输入框]       │  ← 高度 40px，圆角 8px
│                     │
│   [密码输入框]       │  ← 高度 40px，圆角 8px
│                     │
│   [登录按钮]         │  ← 主色背景，全宽，高度 44px
│                     │
│   ───────────────── │  ← 间距 16px
│   还没有账号？注册   │  ← 主色链接
│                     │
└─────────────────────┘
[底部空白 40px]
```

**交互：**
- 输入框 Focus: 边框变 #4F46E5
- 按钮 Hover: 背景变 #4338CA
- 错误提示: 红色文字 #EF4444，显示在输入框下方

**注册页额外元素：**
- 邀请码输入框（在密码框下方）
- 注册按钮
- 已有账号？登录链接

## 五、Figma 操作指引

### 创建步骤

1. **打开 Figma**
   - 访问 https://www.figma.com
   - 登录账号：jackieyy0320@hotmail.com

2. **新建文件**
   - 点击 "Create new design file"
   - 命名为 "Licai Buddy - MVP Design"

3. **创建页面框架**
   - 按照上面的规格，创建 5 个主页面
   - 每个页面创建一个 Frame（按画板尺寸）

4. **设置设计变量**
   - 创建 Color 变量（所有颜色）
   - 创建 Text 变量（所有字号字重）
   - 创建 Spacing 变量（所有间距）

5. **构建组件库**
   - 按钮（Primary/Secondary/Danger）
   - 输入框（正常/Focus/Error）
   - 卡片（默认/统计）
   - 弹窗（添加/编辑）

6. **完善设计**
   - 添加图标（可使用 Figma 内置图标或 Iconify 插件）
   - 调整间距和布局
   - 添加交互原型（点击跳转、弹窗触发）

7. **添加标注**
   - 使用 Figma Dev Mode
   - 添加间距、颜色、字体标注
