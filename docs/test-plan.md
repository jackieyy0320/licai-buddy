## 一、测试策略

### 1.1 测试层级

```
单元测试 (Jest)
    ↓
集成测试 (Prisma + API)
    ↓
端到端测试 (Playwright)
    ↓
用户验收测试 (Jackie)
```

### 1.2 测试原则

- **TDD 强制**：每个新功能必须先写测试
- **自动化优先**：所有回归测试自动执行
- **覆盖率目标**：核心模块 > 80%
- **持续集成**：每次提交自动运行测试

## 三、测试类型

### 3.1 单元测试

**工具：** Jest + React Testing Library

**测试内容：**
- 组件渲染
- Props 传递
- 事件处理
- 状态管理

**示例：**

```typescript
// __tests__/TransactionForm.test.tsx
import { render, screen, fireEvent } from '@testing-library/react';
import { TransactionForm } from '@/components/transactions/TransactionForm';

test('显示成功提示当提交成功', async () => {
  render(<TransactionForm />);
  const input = screen.getByLabelText(/金额/i);
  fireEvent.change(input, { target: { value: '100' } });
  const submitBtn = screen.getByRole('button', { name: /提交/i });
  fireEvent.click(submitBtn);
  expect(screen.getByText(/成功/i)).toBeInTheDocument();
});
```

### 3.2 集成测试

**工具：** Jest + Supertest

**测试内容：**
- API 端点
- 数据库操作
- 业务逻辑

**示例：**

```typescript
// __tests__/api/transactions.test.ts
import { describe, it, expect } from 'vitest';
import { request } from 'supertest';
import { app } from '@/app';

describe('GET /api/transactions', () => {
  it('返回交易列表', async () => {
    const res = await request(app).get('/api/transactions');
    expect(res.status).toBe(200);
    expect(Array.isArray(res.body)).toBe(true);
  });
});
```

### 3.3 端到端测试

**工具：** Playwright

**测试内容：**
- 用户流程
- 跨页面交互
- 浏览器兼容性

**示例：**

```typescript
// e2e/transactions.spec.ts
import { test, expect } from '@playwright/test';

test('添加并查看交易', async ({ page }) => {
  await page.goto('/transactions');
  await page.click('button:text("添加支出")');
  await page.fill('input[name="amount"]', '100');
  await page.click('button[type="submit"]');
  await expect(page.locator('text=成功')).toBeVisible();
});
```

### 3.4 性能测试

**工具：** Lighthouse + WebPageTest

**测试内容：**
- 页面加载时间
- 首次交互时间
- 渲染性能

**指标：**
- LCP < 2.5s
- FID < 100ms
- CLS < 0.1
